# BI Dashboard & Visualization Instructions

This guide outlines how to load and visualize the aggregated Spark outputs to build BI dashboards. 

To maintain the "Big Data" integrity of this project, **never process raw AIS tracking data (81.5 GB) directly in the visualization tools**. Instead, the dashboard consumes the small, pre-aggregated Parquet outputs generated by the Spark pipeline.

---

## Recommended Visualization Approaches

### Option A: Tableau Desktop / Public (Recommended for Local BI)
* **Data Sources:** Load the CSV files exported from the aggregated Parquets (e.g. from `output/tables/` or `results/tables/`) or connect directly to Parquet using the Tableau Hyper API / Amazon Athena.
* **Why:** Excellent mapping capabilities for latitude/longitude grid centers and high-quality charts for presentation screenshots.

### Option B: Databricks SQL Dashboards (Recommended for Cloud BI)
* **Data Sources:** Register the Spark outputs as tables in the Hive metastore/Unity Catalog, then write SQL queries directly inside the Databricks SQL editor.
* **Why:** Keeps the entire pipeline inside the Spark ecosystem.

---

## Aggregated Data Source Mapping

Ensure your visualization tool has access to the following outputs:

1. **Traffic Hotspots (`traffic_hotspots_by_grid`):**
   * *Key Fields:* `grid_lat_center`, `grid_lon_center`, `point_count`, `distinct_vessels`
   * *Purpose:* Plotting the geographic density map.

2. **Congestion Proxy (`waiting_by_grid`):**
   * *Key Fields:* `grid_lat_center`, `grid_lon_center`, `total_waiting_minutes`, `waiting_event_count`, `avg_waiting_minutes`
   * *Purpose:* Port backlog hotspots and idle heatmaps.

3. **Matched Emissions (`ais_mrv_matched`):**
   * *Key Fields:* `ship_type`, `total_co2_emissions`, `total_time_at_sea`, `ais_point_count`, `avg_speed`
   * *Purpose:* Comparing environmental footprint with operational intensity.

## Dashboard Tab Structures

### Tab 1: Global Maritime Traffic Hotspots (Geographic Map)
* **Visual Elements:**
  * **Density Map (Density Mark / Symbol Map):** Plot `grid_lat_center` and `grid_lon_center`. Size the marks by `distinct_vessels` and color by `point_count` (using a hot color scheme like Orange-Red).
  * **Top 10 Chokepoints (Bar Chart):** `grid_id` on the Y-axis, `distinct_vessels` on the X-axis.
  * **Vessel Distribution (Donut Chart):** Share of total AIS points by `vessel_type_group`.
* **Interactivity:** Clicking a vessel type in the donut chart filters the geographic map to show hotspots for that type only.

### Tab 2: Fleet Velocity & Congestion Analysis
* **Visual Elements:**
  * **Speed Distribution by Type (Box & Whisker / Violin Plot):** Displays median, p90, and ranges of speeds for each ship class.
  * **Congestion Heatmap (Map):** Geographic plot of `waiting_by_grid` where mark size and color are mapped to `total_waiting_minutes`. Shows where vessels are sitting idle.
  * **Idle Time vs. Vessel Type (Bar Chart):** Total waiting hours by ship group.
* **Interactivity:** Slider to filter out grids with fewer than $X$ waiting events to eliminate noise from small vessels.

### Tab 3: Carbon Intensity & Activity Correlation
* **Visual Elements:**
  * **Activity vs. Emissions Scatter Plot:** X-axis: `ais_point_count` (activity proxy), Y-axis: `total_co2_emissions` (annual tonnes). Plot each matched vessel as a dot, colored by `ship_type`. Add trend lines to see correlation.
  * **Vessel Emissions Leaderboard (Table):** List of ships showing name, type, and annual CO₂ emissions.
  * **Average Emissions per Hour (Bar Chart):** `ship_type` compared to `total_co2_emissions / total_time_at_sea`.
* **Interactivity:** Drop-down filter to select specific vessel types (e.g. show only Container ships to study their specific speed-to-emissions curve).
